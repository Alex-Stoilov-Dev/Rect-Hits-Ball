# Shapes in C
---
### This is my first C project, where I wanted to attempt making something akin to [Arkanoid](https://en.wikipedia.org/wiki/Arkanoid)

- The project is utilizing the SDL3 Library for Graphics and game logic.
- Currently, it has the working movement for the rectangle that the players use, as well as the ball being affected by gravity.
- There is also basic hit detection, which checks for collisions and upon collision it changes the direction in which the ball travels.

The project is far from finished, but the essentials are built and it would only need to have blocks to break be generated, and then use the colision checks to destroy blocks.
