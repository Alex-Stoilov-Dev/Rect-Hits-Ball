# Shapes in C
---
### This is my first C project, where I wanted to attempt making something akin to [Arkanoid](https://en.wikipedia.org/wiki/Arkanoid)

- The project is utilizing the SDL2 Library for Graphics and game logic.
- Currently, it has working movement for the rectangle the players uses, as well as the ball being affected by gravity.
- There is also basic hit detection, that checks for colisions and upon colision it changes the direction in which the ball travels.

The project is far from finished, but the essentials are built and it would only need to have blocks to break be generated, and then use the colision checks to destroy blocks.
